# Git and DevOps

## Git reference

The [`git-basics/`](git-basics/) section contains concise command references for everyday Git work:

- basic repository operations;
- branching and merging;
- history inspection;
- remotes and fetching;
- tagging;
- restore, reset, and stash.

Review command targets with `git status` and `git diff` before operations that rewrite history or discard work.
